# Анализ факторов успеха создателей adult-контента (OnlyFans & PornHub)

## 📌 Описание проекта
[cite_start]Данный проект посвящен исследованию индустрии adult-контента — одного из самых развитых сегментов онлайн-рынка[cite: 13, 14]. [cite_start]Модели и продюсеры ведут жесткую конкуренцию за внимание аудитории, где популярность напрямую конвертируется в доход[cite: 14, 15]. [cite_start]Однако факторы, определяющие успех, до сих пор плохо формализованы[cite: 16].

[cite_start]**Цель проекта:** Рассмотреть две крупнейшие платформы (OnlyFans и PornHub) и проанализировать связь между активностью в соцсетях и успехом создателей контента[cite: 17, 18].

[cite_start]**Целевая переменная:** Среднее количество просмотров[cite: 19, 20].

---

## 📊 Описание датасета
[cite_start]Датасет **`danzan_girlfriends.json`** [cite: 68] [cite_start]содержит данные о **11 000+** моделях[cite: 29].

### Структура данных:
* [cite_start]**twitter / instagram / onlyfans / tiktok**: URL-адреса профилей в соответствующих социальных сетях[cite: 31, 75, 79].
* **twitter_exists / instagram_exists / onlyfans_exists / tiktok_exists**: Бинарные признаки наличия аккаунта на платформе[cite: 65, 76, 78].
* [cite_start]**videos_count**: Общее количество загруженных видео[cite: 32, 73].
* **views_count**: Общее количество просмотров профиля[cite: 33, 72].
* **average_views**: Рассчитанное среднее количество просмотров на одно видео[cite: 65, 66, 77].
* **num_platforms**: Общее количество внешних платформ, на которых зарегистрирована модель[cite: 67, 78].
* **tags**: Список топ-3 популярных категорий контента (определено через API)[cite: 48, 174, 182].

## 🛠 Технологический стек
Проект реализован на **Python 2025** [cite: 2] с использованием:
* [cite_start]**Сбор данных (Scraping):** `Selenium`, `BeautifulSoup`, `Requests`[cite: 28].
* **Работа с API:**
    * [cite_start]**OnlyFans Rapid API**: получение данных о профилях (id, name, price) и постах[cite: 40, 41, 42, 43, 44].
    * **OpenAI API**: автоматическое определение гендера и жанров видео[cite: 46, 47, 48].
* [cite_start]**Анализ данных (EDA):** `Pandas`, `NumPy`, `Matplotlib`, `re`[cite: 57, 68, 69, 80].

## 📂 Основные этапы реализации

### 1. Scraping & API
* [cite_start]Реализован автоматический сбор данных с карточек моделей Pornhub[cite: 28].
* Настроена интеграция с Rapid API для получения детальной статистики OnlyFans[cite: 40].
* [cite_start]Использована LLM для обогащения данных и классификации тегов[cite: 46, 182].

### 2. Feature Engineering & EDA
* [cite_start]**Парсинг данных:** Написаны функции для конвертации строковых значений просмотров (например, "5M") в численный формат для вычислений[cite: 56, 57, 58, 63].
* **Очистка:** Обработаны аномалии, бесконечные значения (`inf`) и пропуски в данных[cite: 80, 81, 82].
* [cite_start]**Анализ:** Проведено сравнение среднего количества просмотров в зависимости от наличия конкретных соцсетей (в логарифмической шкале)[cite: 109, 110, 137, 138].

## 📈 Ключевые инсайты
* [cite_start]**Мультиплатформенность:** Модели, представленные на 4 платформах, показывают значительно более высокие средние просмотры, чем те, кто ограничен одной площадкой[cite: 90, 99].
* **Влияние соцсетей:** Наличие аккаунтов в OnlyFans, TikTok и Instagram дает кратный прирост к охватам на основной платформе[cite: 109, 110, 137].
* [cite_start]**Топ категорий:** Самыми востребованными жанрами по средним просмотрам оказались `vlog`, `petplay` и `candid`[cite: 167, 174].
