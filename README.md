# Анализ факторов успеха создателей adult-контента (OnlyFans & PornHub)

## Описание проекта
Данный проект посвящен исследованию индустрии adult-контента — одного из самых развитых сегментов онлайн-рынка. Модели и продюсеры ведут жесткую конкуренцию за внимание аудитории, где популярность напрямую влияет на доходы. Однако факторы, определяющие успех модели, до сих пор плохо формализованы.

**Цель проекта:** Рассмотреть две самые популярные платформы подобного контента в мире: OnlyFans и PornHub и проанализировать связь аудитории создателей контента на этих платформах и успех на самих платформах в отдельности.

**Целевая переменная:** Среднее количество просмотров.

## Описание датасета
Датасет **`danzan_girlfriends.json`** содержит данные о **11 000+** моделях.

### Структура данных:
* **twitter / instagram / onlyfans / tiktok**: URL-адреса профилей в соответствующих социальных сетях.
* **twitter_exists / instagram_exists / onlyfans_exists / tiktok_exists**: Бинарные признаки, указывающие на наличие аккаунта на платформе.
* **videos_count**: Количество загруженных видео.
* **views_count**: Общее количество просмотров профиля.
* **average_views**: Среднее количество просмотров на одно видео.
* **num_platforms**: Общее количество платформ, где зарегистрирован пользователь.
* **tags**: Список топ-3 популярных категорий контента.

## Технологический стек
Проект реализован на **Python 2025** с использованием следующих инструментов:
* **Сбор данных (Scraping):** `Selenium`, `BeautifulSoup`, `Requests`.
* **Работа с API:**
    * **OnlyFans Rapid API**: получение данных о профиле (id, name, price, duration, about) и постах.
    * **OpenAI API**: классификация гендера модели и определение жанров видео.
* **Анализ данных (EDA):** `Pandas`, `NumPy`, `Matplotlib`, `re`.

## Основные этапы реализации

### 1. Scraping & API
* С помощью библиотек Selenium, BeautifulSoup и Requests был реализован автоматический сбор данных с карточек моделей на платформе Pornhub.
* В результате был собран датасет из 11 000+ моделей с ключевыми характеристиками их профилей.
* Использован OnlyFans Rapid API для получения данных о стоимости подписки и текстах постов.
* Применен OpenAI API для обогащения данных (гендер и жанры).

### 2. Feature Engineering & EDA
* **Парсинг данных:** Реализована функция `parse_views` для конвертации строковых значений просмотров (например, "5M", "10K") в численный формат `int`.
* **Очистка данных:** Обработка бесконечных значений (`inf`) и заполнение пропусков в средних просмотрах.
* **Создание признаков:** Добавлены столбцы наличия соцсетей и расчет среднего количества просмотров на видео.

## Ключевые инсайты
* **Мультиплатформенность:** Анализ показал, что средние просмотры растут при увеличении числа используемых платформ до 4-х.
* **Влияние соцсетей:** Наличие аккаунтов в OnlyFans, TikTok, Instagram и Twitter значимо повышает средние показатели просмотров (согласно графикам в логарифмической шкале).
* **Топ категорий:** Самыми просматриваемыми тегами по средним показателям стали `vlog`, `petplay` и `candid`.
